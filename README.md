# Fathom

A question log for rabbit-hole learning, laid out as a Swiss typographic poster. To *fathom* something is to finally understand it, and a fathom is also a measure of depth. Each rabbit hole is a numbered band, and every follow-up question branches off it as a square. Click a square to rename it, change its status, write notes, or branch deeper.

It's a single HTML file with no build step. Open `index.html` locally, or use the GitHub Pages copy.

## Saving

- Everything saves in the browser automatically.
- **Customize → Your data → Save to a file…** also autosaves to a JSON file on disk. This needs Chrome or Edge.
- **Customize → GitHub sync** keeps devices in sync through a JSON file in a private repo. You need a fine-grained token limited to that repo, with Contents set to Read and write. The token stays in each browser and is never committed.

No question data lives in this repo.
